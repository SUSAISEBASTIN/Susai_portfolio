# Susai Sebastin P - Portfolio

Static portfolio site (plain HTML, CSS, JS). No build step, so it runs as-is on GitHub Pages.

## Deploy
1. Create a repo, e.g. `susai-portfolio` (or `<username>.github.io` for a root URL).
2. Upload everything in this folder to the repo root (keep `index.html` at the top level).
3. Repo Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`.
4. Wait about a minute. Your site is at `https://<username>.github.io/<repo>/`.

All paths are relative, so it works under a repo sub-path too.
